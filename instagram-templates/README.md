# Peptide Pharma Instagram templates

1080×1350 (4:5). Open any HTML file in a browser, zoom to 100%, screenshot **only** the 1080×1350 canvas (not the grey page chrome).

Brand assets match the site: Inter + Space Grotesk, teal `#165d74` / accent `#2f9a86`, helix logo, `public/images` vials.

Dashed outlines mark **swap-per-post** fields. They will appear in the screenshot — remove the `.swap` class (or the outline in `shared.css`) before export.

Shop listings on this site are **research use only**. Templates use that mark, not a TGA-approved badge.

## Swap vs fixed

**Swap each post:** product image, product name, price, short line, offer headline, thumbs, educational headline/body, quote + name/city + stars, lifestyle photo + caption.

**Keep:** Peptide Pharma wordmark + `logo.svg`, colour system, grid fade, RUO / not-for-consumption footer, protocol step copy (unless you rewrite a slide), “Read more on our Science page”.

**Quote card:** replace every `PLACEHOLDER` with a verified, permission-given quote. No invented reviews. No treatment outcomes.

**Lifestyle card:** put a real photo in `REAL PHOTO GOES HERE`. No stock or AI people.

Not included (on purpose): before/after layouts, fabricated customer photos, health/treatment-outcome claim templates.
