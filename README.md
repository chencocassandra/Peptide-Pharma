# Peptide Pharma

Marketing site for an independent peptide therapeutics institute — science, pipeline, research reagents, and collaboration contact.

Built with Next.js (App Router) and Tailwind CSS, reconstructed from the public Vercel preview.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and import the repo in Vercel. Production domain: [peptidepharma.com](https://peptidepharma.com).
